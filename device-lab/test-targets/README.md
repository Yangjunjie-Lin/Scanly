# Beta 4 physical test targets

`ground-truth.json` is the decoder-independent source of expected format and payload. It is reviewed before a camera session and must never be rewritten from Scanly output.

Run `npm run device:targets:generate` to create deterministic PNG targets and two printable sheets. The second sheet contains the four-target multi-code set and both same-payload labels. Run `npm run device:targets:verify` in CI to compare every generated byte and SHA-256 against a clean regeneration. `same-payload-a` and `same-payload-b` intentionally encode identical data but represent two separately labelled physical instances.

Generated artwork is project-owned test material. It is not physical-device evidence. Printing or displaying a target does not prove that a test was executed.
