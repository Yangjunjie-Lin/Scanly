# Generated industrial difficulty matrix

`manifest.json` expands deterministically to 42 cases: 14 difficulty types at low, medium, and high severity across QR, Data Matrix, PDF417, Code 128, and EAN-13. `baseByDifficulty` makes the cross-symbology matrix explicit instead of relying on fixture order. The benchmark creates derivatives in memory; generated derivatives are not real photographs.

The transforms never use image generation, inpainting, neural super-resolution, payload hints, fixture IDs, or hard-coded decoded data.
