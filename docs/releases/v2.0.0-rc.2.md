# Scanly SDK v2.0.0-rc.2 — final validation candidate

RC2 preserves the RC1 feature/API/ABI freeze and adds the unified Web + Native
physical validation campaign. It supports the frozen eight barcode symbologies,
Web, Node, React, Native iOS, and Native Android runtimes, realtime scanning,
tracking, batch, and industrial recovery. The architecture remains local and
privacy-first; DPM remains experimental and is not certified.

This candidate is not Stable. In the current execution environment no real
iPhone, Android device, or provider-attested device farm is available, and no
production release signing credentials are available. Therefore the truthful
decision is `V2_STABLE_RELEASE_NO_GO` with
`BLOCKED_EXTERNAL_PHYSICAL_HARDWARE` and
`BLOCKED_EXTERNAL_RELEASE_CREDENTIALS`. Automated CI or emulation cannot be
used to replace those physical rows.
